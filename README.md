# Mini Shopping Website

A simple first-year CSE mini project built using HTML, CSS and JavaScript.

## Features
- Product listing
- Add to cart
- Remove items from cart
- Automatic total calculation
- Customer login-style checkout details
- Address collection
- Payment method selection
- Order confirmation

## Files
- `index.html` - main webpage
- `style.css` - design and layout
- `script.js` - shopping cart and checkout functionality

## How to run
Open `index.html` in a web browser.

## GitHub Pages
This project can be published using GitHub Pages:
Settings → Pages → Deploy from branch → `main` → `/ (root)` → Save
